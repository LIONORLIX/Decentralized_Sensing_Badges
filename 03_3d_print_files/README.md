# 3D Printing Files

This directory contains STL meshes that can be imported directly into a slicer:

- `Badge_Circle.stl`: circular badge version.
- `Badge_test.stl`: test badge version.

No exported G-code, GCO, 3MF, or BGCODE file was found in the project. Import an STL into the slicer for the target printer, configure the printer, material, layer height, infill, supports, and build plate, then export the machine-specific slicing output.
